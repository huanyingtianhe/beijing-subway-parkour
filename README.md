# 北京地铁跑酷

在按高德地铁图还原的北京地铁线网上跑酷的网页游戏：27 条线路、410 座车站，Three.js 渲染，赛博朋克风格。

## 怎么玩

在线玩：https://beijing-subway-parkour.vercel.app

本地玩：双击 `index.html`（或 `play.html`）用浏览器打开（需要联网加载 Three.js）。

两种模式：

- **地铁一日游**：末班车开走后线路进入夜间检修。选起点车站和方向，自动往前跑：跳过施工护栏、滑过检修龙门架、躲开工程车，从检修斜梯跑上停着的列车车顶吃金币；到换乘站按数字键换线。每吃 30 个金币加一条命。
- **抢末班车 · 20 人**：深夜线路一段段停运，最后一班车即将发车。你和 19 个电脑对手从随机车站出发，安全区围绕某个车站不断缩小，圈外停运检修、持续掉血，活到最后挤上末班车。自己控制前进后退，对手出拳前会蓄力 0.6 秒，换道、跳、滑铲或后退都能躲开。每吃 10 个金币回 10 HP。

| 按键 | 作用 |
|---|---|
| ← → / A D | 换道 |
| ↑ / 空格 | 跳（抢末班车模式里 ↑/W 是前进，S/↓ 后退，C 滑铲） |
| ↓ | 滑铲 |
| R | 掉头 |
| F | 出拳（抢末班车模式） |
| 1–6 / Q E | 换乘时选线路和方向 |
| M | 全屏地图 |
| P / Esc | 暂停 |

## 文件

- `game.js` —— 游戏代码（线路数据位置留有 `/*__DATA__*/` 占位）
- `bgm.mp3` —— 背景音乐（与介绍视频同一段电子乐，64 秒无缝循环）
- `lines.json` —— 线路与车站数据（示意坐标、颜色、经纬度），来自 [高德地铁图](https://map.amap.com/subway/index.html)
- `page.html` —— 页面与样式模板，`build.py` 会把 `game.js` 和数据内联进来
- `index.html` / `play.html` —— 构建产物，可直接打开的完整网页（内容相同）

修改 `game.js` 或 `page.html` 后运行：

```bash
python build.py
```

会更新 `page.html` 里的内联脚本，并重新生成 `index.html` 和 `play.html`。

在地址后加 `#debug` 会在页面上暴露 `window.__bj` 调试对象。
